# Automatyka od zera: dokumenty prawne

Polityka prywatności i regulamin aplikacji „Automatyka od zera”, publikowane przez GitHub Pages:

- https://michalbednarek-maker.github.io/automatyka-legal/polityka-prywatnosci.html
- https://michalbednarek-maker.github.io/automatyka-legal/regulamin.html

Nie edytuj tych plików ręcznie. Źródłem jest blok `legal` w aplikacji; strony generuje
`node _content/tools/gen-legal.js` w repozytorium aplikacji (wynik w `docs/legal/`),
a potem kopiuje się je tutaj.
